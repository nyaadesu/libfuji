# libfuji

A library that can connect connect to Fujifilm digital cameras over WiFi, Bluetooth, and USB.
Reverse-engineered through [black-box testing](https://github.com/petabyt/vcam) of Fuji's apps and software.

This is currently being used for the [Fudge project](https://github.com/petabyt/fudge).

Implements support for:
- Wireless communication mode (Xapp/Camera Connect)
- Legacy and secure Bluetooth LE pairing modes
- PC Autosave mode
- Wireless tether shoot/USB tether shoot (X Acquire)
- Raw conversion mode (Raw Studio)
